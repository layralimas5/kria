# Vynkio

Influenciadores e vídeos com IA, pagos por crédito.

- **Estúdio:** gera foto (texto) e foto com persona, e anima imagens em vídeo (Kling, Veo 3.1).
- **Personas:** descreve a pessoa, gera retratos até acertar, salva e usa o mesmo rosto em tudo.
- **Galeria:** tudo que foi gerado, com baixar, animar e virar persona.
- **Créditos:** 20 de boas-vindas, pacotes avulsos por Pix ou cartão, extrato completo.

```bash
npm install
cp .env.example .env.local   # URL e anon key do Supabase
npm run dev                  # http://localhost:5231
npm run check                # tipos + testes
npm run dev:demo             # app com dados de exemplo, sem Supabase
```
